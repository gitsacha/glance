# Refresh active Quick Look previews

Observe the selected path while its Quick Look view is alive. Metadata polling detects stable writes and atomic replacement, retries transient failures and retains the last good view. Replacement web controllers transfer scroll position, Contents visibility and Find text after rendering completes; observation stops when the view disappears.

Depends on web-controls (and its web-modernization dependency). The exported delta excludes those dependencies; the worktree includes them. Folder/database exemptions belong to their separate contributions. The focused harness exercises real observer/state APIs without writing the installed application's shared usage statistics; Xcode compiles the actual MainVC integration.
